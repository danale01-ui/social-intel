# social-intel

סקיל ל-Claude Code שקורא עמודי פייסבוק ופרופילי אינסטגרם ושולף מודעות מספריית המודעות של מטא, הכל מכלי אחד.

## מה הוא עושה

- **אינסטגרם:** אוסף פוסטים ורילס מפרופיל, ולכל פוסט מחזיר כיתוב, לייקים, מספר תגובות, תאריך ואת התגובות עצמן.
- **פייסבוק:** קורא פוסטים, כיתובים, תגובות, ומספרי תגובות ושיתופים מעמוד.
- **ספריית המודעות:** שולף את המודעות שרצות אצל מתחרה או בקטגוריה, מנקד אותן לפי ותק, וריאציות ורוחב המפרסם, מוריד את הקריאייטיב וכותב דוח.

## התקנה

1. מעתיקים את התיקייה `social-intel` אל `~/.claude/skills/`.
2. לאינסטגרם ולפייסבוק: מתקינים את התוסף Claude in Chrome, ונכנסים בכרום לחשבונות פייסבוק ואינסטגרם.
3. לספריית המודעות: Node 18 ומעלה ו-Google Chrome מותקן, ואז:
   ```bash
   cd ~/.claude/skills/social-intel/scripts/ads && npm ci && node doctor.mjs
   ```
   אם כל 8 הבדיקות עוברות, הכלי מוכן.

## שימוש

בתוך Claude Code כותבים, למשל:
- "תסרוק את האינסטגרם של `<handle>` ותגיד לי מה עובד אצלם"
- "מה כותבים בתגובות בעמוד הפייסבוק של `<page>`"
- "מה מריצים עכשיו בספריית המודעות בקטגוריה `<נושא>`"

כל ההוראות נמצאות ב-`SKILL.md`.

## חשוב לדעת

- הכלי קורא בלבד. הוא לא עושה לייק, לא עוקב, לא מגיב ולא נוגע בהודעות פרטיות.
- הסריקה בפייסבוק ובאינסטגרם רצה מהחשבון שלך ובקצב של אדם. סריקה מסיבית מסכנת את החשבון.
- באינסטגרם נאספות רק התגובות שמוצגות בטעינה הראשונה של הפוסט.
- בפייסבוק התאריך נקרא רק מצילום מסך, ופוסטים בשפה זרה מוצגים כבר מתורגמים.
