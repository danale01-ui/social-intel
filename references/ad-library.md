# ספריית המודעות של מטא: מדריך מלא

הסקריפטים ב-`scripts/ads/` שולפים את המודעות שהספרייה הציבורית מציגה, מנקדים אותן וכותבים דוח. אין עלות, אין מפתח API ואין צורך בהתחברות.

## הרצה

```bash
cd scripts/ads
npm ci

# 0. בדיקה, 20 שניות. מונעת אבחון שגוי אחר כך
node doctor.mjs

# 1. איסוף. --min-age מבקש מהשרת רק מודעות ותיקות.
#    --with-media מוריד את הקריאייטיב באותה ריצה, לפני שהקישורים החתומים פגים
node harvest.mjs --q '<מילת חיפוש>' --country IL --min-age 30 --with-media --out ../runs/cat

# 2. ניקוד ודוח
node rank.mjs --in ../runs/cat --min-age 30 --top 12

# 3. רק אם לא הורדת מדיה באיסוף
node fetch-media.mjs --in ../runs/cat --top 8 --images

# 4. חידוש קישורי מדיה להרצה ישנה שהקישורים שלה פגו
node refresh-media.mjs --in ../runs/cat --top 8 --images
```

**לפי מפרסם ולא לפי מילת חיפוש:** `node harvest.mjs --page-id <PAGE_ID> --country IL --out ../runs/competitor`. את ה-page-id מוצאים ב-`ranked.json` של איסוף קודם, בשדה `page_id`, או בכתובת של עמוד המפרסם בספרייה.

**קטגוריה שלמה.** מילת חיפוש אחת לא מכסה שוק, כי מפרסמים מתארים את אותו מוצר במילים שונות. אוספים כמה חיפושים, ממזגים אותם ומנקדים פעם אחת:

```bash
node harvest.mjs --q '<מילה 1>' --min-age 30 --with-media --out ../runs/kw-1
node harvest.mjs --q '<מילה 2>' --min-age 30 --with-media --out ../runs/kw-2
node merge.mjs --out ../runs/merged ../runs/kw-1 ../runs/kw-2
node rank.mjs --in ../runs/merged --min-age 30 --top 25
```

**דגלים:** `--country US` (כל קוד ISO), `--status all` (כולל מודעות שכבר כבו), `--media video`, `--all` (עד שהקטגוריה נגמרת), `--media-cap 40`, `--headed` (רואים את הדפדפן). ב-`rank.mjs`, הדגלים `--exclude` ו-`--require` מסננים תוצאות לא רלוונטיות, והמסוננות מופיעות בדוח ברשימה נפרדת.

## מה יוצא

- `report.md`: הדוח
- `ranked.json`: כל הקונספטים עם הסיגנלים והניקוד
- `media-manifest.json`: קישורי הווידאו והתמונות של המודעות המובילות
- `raw-ads.json` ו-`meta.json`: הגלם, לביקורת
- `creative/`: הקבצים שהורדו, עם `index.json`

## הניקוד

ארבעה רכיבים, שמסתכמים ב-100. הנוסחה עצמה נמצאת ב-`rank.mjs`.

- **ותק, עד 50:** ציון מלא מ-60 יום ומעלה
- **וריאציות, עד 20:** מפרסם שמייצר כמה גרסאות לאותו קונספט משקיע בו
- **רוחב המפרסם, עד 15:** ציון מלא מ-10 מודעות פעילות ומעלה
- **חזרת כותרת, עד 15:** אותו הוק בכמה מודעות מעיד על הימור מודע

**דירוגים:** `מוכח` (פעילה 30 יום ומעלה), `בהרחבה` (14 יום ומעלה, עם 3 וריאציות ומעלה), `חדש` ו-`כבוי`. לדוח נכנסים רק `מוכח` ו-`בהרחבה`.

## איך זה עובד, ומתי זה יישבר

הספרייה הציבורית מדברת עם `/api/graphql/`. הסקריפט טוען את הדף פעם אחת, לוכד את בקשת החיפוש שהדף שולח, ומשחזר אותה עם סמן עד שהתוצאות נגמרות. כשיש מעט תוצאות, המודעות נקראות ישירות מה-HTML.

ה-API הרשמי (`/ads_archive`) לא משמש כאן, כי מחוץ לאיחוד האירופי הוא מחזיר רק מודעות פוליטיות.

- בכל עמוד יש 10 מודעות, ואין הגבלה על מספר העמודים. 300 מודעות לוקחות בערך חמש דקות. הגלם נשמר כל 5 עמודים, אז נפילה באמצע לא מוחקת את מה שכבר נאסף.
- אין מיון לפי ביצועים. לכן מצמצמים את התוצאות עם `--min-age` במקום למיין.
- קישורי המדיה פגים אחרי כמה שעות. `--with-media` מוריד את הקבצים כבר באיסוף.
- אם מטא משנה את המבנה, `harvest.mjs` יוצא עם קוד 3. חיפוש שפשוט לא החזיר תוצאות יוצא עם קוד 2. `doctor.mjs` מראה איזו הנחה נשברה.
- הרצות תכופות מאותו IP עלולות להיחסם. אל תריצו בלולאה.

## חוקים

1. **ותק אינו ביצועים.** כל קונספט מוצג עם הסיגנלים שתומכים בו.
2. **לא ממציאים מספרים.** אין בספרייה CTR או תקציב, ולכן גם לא בדוח.
3. **מבנה ולא מילים.** לא מעתיקים קופי, טענה או סיפור ממודעה של מתחרה.
4. **הגלם נשמר**, כדי שכל שורה בדוח תהיה ניתנת לבדיקה.
